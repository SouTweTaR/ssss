# CritAim — Fabric 1.21.4

Клиентский мод: криты в прыжке + плавная наводка на ближайшего игрока.

## Управление
- **R** — наводка вкл/выкл
- **V** — авто-криты вкл/выкл
- Клавиши можно поменять в «Настройки → Управление → CritAim».
- Статус показывается в левом верхнем углу.

## Как работает
- **Наводка:** ищет ближайшего видимого игрока в радиусе 6 блоков и в конусе 90°, плавно доводит камеру в грудь.
- **Криты:** если цель в ~3.5 блоках и удар почти заряжен — прыгает; на падении (fallDistance > 0), при полном заряде и прицеле на цели — бьёт. Перед ударом сбрасывает спринт (иначе крита не будет).

Настройки (радиус, плавность, FOV) — константы в начале `CritAimClient.java`.

## Сборка
Нужна **Java 21**.

```bash
gradle wrapper        # один раз, если нет gradlew
./gradlew build       # Windows: gradlew.bat build
```
Готовый jar: `build/libs/critaim-1.0.0.jar` → кинуть в `.minecraft/mods` вместе с Fabric API.

Если Gradle ругается на версии — возьми свежие значения для 1.21.4 с https://fabricmc.net/develop и поправь `gradle.properties`.

Либо просто открой папку в IntelliJ IDEA — она сама подтянет Gradle.
